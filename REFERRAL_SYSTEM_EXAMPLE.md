# Programa de Referidos C-Tracker

## Descripción General

C-Tracker ofrece un programa de referidos que permite a los usuarios generar ingresos pasivos al invitar nuevos traders a la plataforma. El sistema incluye comisiones por trading y participación en servicios premium como el Bot de Volumen.

## Estructura de Comisiones

### Trading Tradicional
- **Comisión:** 0.5% del volumen de trading del referido
- **Pago:** En BNB
- **Acumulación:** Se deposita en el contrato inteligente
- **Retiro mínimo:** 0.001 BNB

### Bot de Volumen (Nuevo)
- **Comisión:** 50% de las ganancias del Bot de Volumen del referido
- **Aplicable:** Solo para usuarios que contraten el servicio a través de enlace de referido
- **Distribución:** Automática o manual según configuración

## Bot de Volumen - Servicio Premium

### Qué es el Bot de Volumen
Servicio automatizado que genera volumen de trading para tokens específicos, mejorando:
- Liquidez aparente
- Posicionamiento en rankings
- Atractivo para nuevos inversores
- Estabilidad de precio

### Estructura de Comisiones para Referidos
```
Cliente contrata Bot de Volumen por $500/mes
└── Ganancia neta del bot: $300/mes
    └── 50% para referidor: $150/mes
    └── 50% para protocolo: $150/mes
```

### Beneficios para el Referidor
- **Ingresos recurrentes:** Mientras el cliente mantenga el servicio
- **Alta rentabilidad:** 50% de participación en ganancias
- **Acumulativo:** Cada nuevo cliente suma a los ingresos totales
